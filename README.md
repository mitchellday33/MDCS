# MDCS Website

Static website for **Mitch Day Coaching Services**.

## Files

- `index.html` — page structure and website content
- `main.css` — colors, layout, responsive styling, and animations
- `app.js` — mobile navigation, mentorship selection, and inquiry form
- `mdcs-ice-hero.png` — hero background image

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all four website files and this README to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** in the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/(root)` folder, then click **Save**.
7. GitHub will display the public website URL after deployment finishes.
